# 🕹️ Neon Tetris

Sebuah adaptasi modern dari permainan klasik Tetris dengan estetika **Neon Retro**. Proyek ini dibuat menggunakan JavaScript murni (Vanilla JS) dengan manipulasi Canvas API untuk memberikan pengalaman bermain yang mulus dan responsif.

## 🌟 Fitur Utama

- **Estetika Neon:** UI yang gelap dengan efek glow pada balok dan teks menggunakan CSS shadow properties.
- **Logika Tetris Lengkap:** Termasuk rotasi matriks, deteksi tabrakan (collision detection), dan *wall kicking*.
- **Sistem Scoring:** Perhitungan skor berdasarkan jumlah baris yang dihapus sekaligus (Single, Double, Triple, Tetris).
- **Progressive Difficulty:** Kecepatan jatuh balok akan meningkat seiring dengan kenaikan level setiap 10 baris yang berhasil dibersihkan.
- **Responsive Canvas:** Ukuran area bermain yang proporsional untuk kenyamanan visual.
